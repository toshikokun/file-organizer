# ファイル整理ツール

## 概要

フォルダ内のファイルを拡張子によって自動的に分類し、
対応するフォルダに整理するプログラムです。

## 主な機能

- ファイルの拡張子を判定
- 拡張子に対応するカテゴリフォルダを自動作成
- ファイルを対応するフォルダに自動で移動
- 未対応の拡張子は「その他」に分類

## 使用方法

`organizer.py` の `dir_path` に、
整理したいフォルダの絶対パスを設定します。

``python
dir_path = Path("整理したいフォルダのパス")``
そのあと、ターミナルからプログラムを実行します。

``python 
organizer.py``
実行すると、フォルダ内のファイルが拡張子に応じて自動的に分類されます。
